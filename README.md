# Twinkle – Social Mobile App UI/UX Concept

Twinkle is a social mobile application UI/UX concept designed in Figma.  
The project focuses on creating a fun, engaging, and user-friendly social experience where users can create profiles, connect with others, participate in challenges, explore events, earn rewards, and share content.

## Project Overview

The goal of Twinkle is to design a visually consistent and easy-to-use mobile social platform with a playful space-inspired theme.

The interface was designed with a focus on clear navigation, intuitive user flows, visual hierarchy, and consistent screen layouts.

## Key Features

- User onboarding
- Account creation and sign-in
- Google sign-in option
- User profile setup
- Profile customization
- Social feed
- Comments and social interactions
- Star Buddies / friend connections
- Cosmic Challenges
- Galaxy Events
- Cosmic Rewards
- Quotes and creative content
- Fashion and lifestyle-related sections
- Community-focused interactions

## UI/UX Focus

This project focuses on:
